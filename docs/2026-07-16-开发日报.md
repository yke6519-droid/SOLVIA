## 一、今日完成

### 1. 后端工程收口

- 后端正式统一为 FastAPI API 服务。
- 移除正式 CLI 入口和 `main.py` 内置 HTML 页面。
- 保留 `backend/temp/` 文件读写测试环境和旧定时任务文件。
- Uvicorn 自动重载限制为只监听 `backend/`，避免扫描 `.pnpm-store` 中的失效路径。

推荐启动命令：

```powershell
python -m uvicorn backend.app.main:app --reload --reload-dir backend --host 0.0.0.0 --port 8001
```

### 2. 修复预测缓存问题

- 找到逻辑删除缓存仍占用唯一索引的问题。
- 缓存写入改为 UPSERT。
- 重新预测时可以覆盖原有无效记录，并将 `status` 恢复为有效状态。
- 避免出现“日志显示写入成功，但数据库实际没有更新”。

### 3. 完善会话管理

- 会话名称从消息记录中独立出来，避免重复保存。
- 第一条用户消息自动截取最多 10 个字符作为会话名称。
- 支持用户手动重命名，手动名称不会被自动标题覆盖。
- 前端优先展示会话名称，不再直接显示会话 ID。

### 4. 完善 AskUser 交互

- 前端支持 AskUser 确认卡片。
- 用户提交回复后，可以唤醒原来的 Agent 执行流程。
- 明确关键预测确认不能只依赖 Prompt，需要由后端确定性确认门控制。
- 后续复杂任务可以继续演进为显式状态机。

### 5. 优化图表卡片

- 图表标题、指标和数据类型统一中文。
- 增加站点、时间范围和统计粒度。
- 横纵轴增加名称与单位。
- Tooltip 支持查看具体时间点和发电量。
- 优化深浅模式配色。
- 历史图表可以根据快照重新渲染。

### 6. 对话摘要真正异步化

- 新增会话级摘要任务管理器。
- SSE 返回 `done` 后，前端不再等待摘要生成。
- 同一个会话同时只执行一个摘要任务。
- 摘要失败只记录日志，不影响当前对话。
- FastAPI 关闭时统一清理后台任务。
- 流式接口和普通聊天接口复用同一套调度逻辑。

### 8. 敲定通用图表架构

确定最终方向：

- 业务工具负责真实查询、预测和多站点聚合。
- 业务工具产出 `DatasetArtifact`。
- Agent 只能在图表能力注册表中选择，并提交受限 `ChartPlan`。

- 前端根据模板转换为 ECharts 配置。
- 图表通过独立 `chart_spec` SSE 事件传输。
- 历史会话保存版本化 ChartSpec 快照。
- 多站点横向对比作为主要业务案例。

文档：`docs/2026-07-16-通用图表能力架构与分阶段实施方案.md`

## 二、今日踩坑

1. `async def` 不代表调用方不会等待，执行 `await` 仍会阻塞当前请求。
2. 模型输出标准 JSON，不代表前端可以渲染；必须进入正式结构化事件通道。
3. Prompt 只能指导模型，不能代替工具参数、能力注册表和后端校验。
4. 逻辑删除记录仍可能占用唯一索引，必须同时设计恢复和 UPSERT 策略。
5. Uvicorn 不应扫描整个前后端仓库，前端热更新由 Vite 独立负责。
